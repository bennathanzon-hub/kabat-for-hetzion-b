# ארכיון בטיחות

אתר לצפייה וחיפוש בכל התחקירים ותיקי הבטיחות (PDF ו-Word).

אין לו שרת ואין מסד נתונים. הקבצים יושבים בתיקייה בתוך הפרויקט, והאתר נבנה מהם אוטומטית.
האירוח ב-Cloudflare Pages חינמי ולא דורש כרטיס אשראי. האתר מוגש מרשת השרתים העולמית של Cloudflare, כך שאין שרת אחד שיכול ליפול ולהשבית אותו.
GitHub שומר עותק מלא של כל הקבצים, כולל היסטוריה של כל שינוי, כך שהוא משמש גם כגיבוי.

---

## הוספת תחקיר או תיק בטיחות

כל הקבצים נמצאים כאן:

```
public/files/
├── תחקירים/
└── תיקי בטיחות/
```

**קובץ אחד** — שים אותו ישירות בתיקייה המתאימה. שם הקובץ הוא השם שיופיע באתר:

```
public/files/תחקירים/20.09.2026 תחקיר נפילה ממדרגות - מבנה 4.pdf
```

**כמה קבצים לאותו תחקיר או תיק** — צור תיקייה בשם התחקיר ושים בה את כל הקבצים:

```
public/files/תיקי בטיחות/15.05.2026 תיק בטיחות - אולם ספורט/
├── תיק אולם ספורט.docx
└── נספח כיבוי אש.pdf
```

כללים:
- התאריך בתחילת השם הוא אופציונלי. אפשר לכתוב אותו `20.09.2026` או `2026-09-20`. פריטים בלי תאריך יופיעו בסוף הרשימה.
- סוגי קבצים: PDF, ‏DOC, ‏DOCX. קבצים אחרים לא יוצגו.
- גודל מרבי: 25MB לקובץ. קובץ גדול יותר יעצור את העדכון של האתר עד שיוסר.
- לא להשתמש בתווים `#` `%` `?` בשמות.

### דרך האתר של GitHub (בלי להתקין כלום)

1. נכנסים לריפו ב-GitHub, ופותחים את `public/files` ואז את `תחקירים` או את `תיקי בטיחות`.
2. לוחצים על **Add file**, בוחרים **Upload files** וגוררים את הקובץ או את התיקייה.
3. לוחצים על **Commit changes**.

אחרי כדקה, הקובץ מופיע באתר.

כדי למחוק או לשנות שם: פותחים את הקובץ ב-GitHub, לוחצים על `⋯` ובוחרים **Delete file**. כדי לשנות שם, מעלים אותו מחדש בשם הנכון.

## הקמה ראשונית (פעם אחת)

### 1. GitHub
1. פותחים חשבון ב-[github.com](https://github.com).
2. יוצרים ריפו חדש (**New repository**) ומסמנים אותו **Private**.
3. מעלים אליו את כל קבצי הפרויקט, חוץ מהתיקייה `node_modules` אם היא קיימת.

### 2. Cloudflare Pages
1. פותחים חשבון חינמי ב-[dash.cloudflare.com](https://dash.cloudflare.com).
2. נכנסים ל-**Workers & Pages**, לוחצים **Create application**, בוחרים **Pages** ואז **Import from an existing Git repository**.
3. מחברים את חשבון ה-GitHub ובוחרים את הריפו.
4. בהגדרות הבנייה:
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
5. לוחצים **Save and Deploy**.

בסיום מקבלים כתובת בסגנון `kabat-archive.pages.dev` לשתף עם הצוות. מעכשיו, כל שינוי ב-GitHub מעדכן את האתר אוטומטית.

אם עדכון נכשל (למשל קובץ גדול מדי), האתר ממשיך להציג את הגרסה הקודמת. הסיבה מופיעה ב-Cloudflare תחת **Deployments**.

## פרטיות

כל מי שיש לו את הכתובת יכול לצפות בקבצים. האתר מסומן כך שמנועי חיפוש לא יאנדקסו אותו, אבל הוא לא מוגן בסיסמה. אם בהמשך תרצה להגביל את הגישה לאנשי הצוות בלבד, אפשר להפעיל את Cloudflare Access על האתר בלי לשנות את הקוד.

## הרצה על המחשב (לא חובה)

צריך [Node.js](https://nodejs.org) בגרסה 20 ומעלה.

```bash
npm install
npm run dev
```

ואז לפתוח בדפדפן את http://localhost:5173. קובץ שמוסיפים לתיקייה מופיע מיד.

## מבנה הפרויקט

```
public/files/      הקבצים — זה המקום היחיד שצריך לגעת בו ביום-יום
src/App.jsx        הממשק
src/styles.css     העיצוב
vite.config.js     סורק את public/files ובונה ממנה את הרשימה
public/_headers    חוסם אינדוקס במנועי חיפוש
```
